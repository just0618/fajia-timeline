# 法嘉时间档案 V0.6 · PART 03 五月正式章

这一版把「五月正式事件集 V1」真正接进五章节手账框架。

## 这版主要改了什么

- PART 03 从“试做章”升级为 **ready / 正式事件集 V1**；
- 五月预览内置 16 个现实节点，便于不连接本地数据库时先看页面结构；
- 正式支持 `text_only_sensitive`：05.04、05.19 这类私人行程只显示日期/城市级信息，不显示跟拍照片、精确站点、车次或具体时刻；
- `medium_high` 节点在目录里显示“待补官方源”，不伪装成 confirmed；
- 扩展事件类型：首播、音乐上线、线上互动、线下活动、公开日常、出行直播等；
- 底部本章时间轴用不同节点形态区分私人行程 / 公开节点；
- 保留手机端“左页 → 右页 → 下一事件”的逐页翻阅逻辑。

## 最重要：把你电脑上最新的母数据库导出同步进来

先确保数据仓库已经运行：

`import_may_2026_chapter_windows.bat`

然后在本网站文件夹双击：

`sync_latest_from_database_windows.bat`

脚本默认读取：

`E:\fajia-timeline\fajia-timeline-data\data\export\dual_timeline.json`

它会自动：

1. 检查五月是否已经有正式事件集；
2. 覆盖网站 `data/dual_timeline.json`；
3. 重新生成 `timeline-data.js`；
4. 同步数据仓库 `media/`；
5. 从事件里的 `media_assets` 自动生成网站 `media-assets.js`。

如果发现五月节点少于 12 个，脚本会停止，避免旧版 JSON 把网站正式五月数据覆盖掉。

## 五月隐私边界

对于可确认但来源涉及非公开私人行程的信息：

- 保留：日期、城市级节点、参与者；
- 不展示：跟拍照片、精确站点、车次、班次、酒店、具体时刻、跟拍来源。
