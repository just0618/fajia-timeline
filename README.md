# 法嘉时间档案 V0.4.1 · 事件语义修正版

这一版建立“不同事件使用不同右页逻辑”的规则，不再强迫每个节点都套用“后来，我们看见了这些”。

## 五种阅读模式

- `live_record`：直播发生时即被看见。左页记录事件，右页作为直播现场记录；若有同日/后续帖子，再作为补充。
- `original_post`：事件本身发生在公开平台上，例如毕业论文致谢公开、《答案是你》。右页显示原始公开记录。
- `dual_time`：现实先发生、公开物料后到来，例如 Arena 拍摄。
- `experience_only`：目前只确认现实事件。电脑端右页留白但不显示“待续”；手机端直接跳到下一事件。
- `evidence`：IP 属地等证据线索，继续使用线索/证据页。
