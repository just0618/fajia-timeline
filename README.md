# 法嘉时间档案 V0.5 · 五章节总框架

这一版先解决“整本书怎么读”，暂时不继续堆单页素材。

## 核心结构

打开书后先进入 **五章节总时间轴**：

1. PART 01｜10.10 — 杀青
2. PART 02｜杀青后 — 剧播前
3. PART 03｜2026 · 05
4. PART 04｜2026 · 06
5. PART 05｜2026 · 07

五个 Part 都可以点击。前两章先展示“框架已建、内容待整理”；5、6、7 月会自动读取当前 `timeline-data.js` 中对应月份的现实事件。

## 本版阅读路径

`封面 → 五章总时间轴 → 选择 Part → 本章现实时间轴 → 选择具体事件 → 事件手账`

不再把全部事件直接铺成一条很长的时间线。

## 时间线整理原则

主轴固定为：

`全部官方公开发布 → 提取时间/地点/造型/IP/行程等线索 → 建立现实事件 → 按现实发生日期排序 → 把相关公开记录挂回现实事件`

因此：

- 帖子发布时间不是主时间线本身；
- 直播可以是“发生即被看见”；
- 社交平台公开互动可以是 `original_post`；
- 拍摄等事件可使用 `dual_time` 展示“现实发生 → 后续公开”；
- 只有发布时间、无法确认拍摄时间的图片，先留在公开档案层，不强行反推。

## 当前数据状态

当前网页沿用 V0.4.1 的语义修正数据：

- 直播：`live_record`
- 原始公开事件：`original_post`

- 公开线索：`evidence`
