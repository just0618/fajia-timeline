法嘉时间档案 V0.6.2｜PUBLIC INTERACTION 前端补丁
====================================================

这是一份 patch-only 更新，只覆盖下列文件：

  app.js
  styles.css
  index.html
  sync_latest_from_database_windows.bat
  scripts\sync_from_data_repo.py

不要覆盖 data\、media\，也不要删除现有素材。

本版变化
--------
1. 五月主时间轴不再把 online_interaction 当成与直播/出行同权重的普通事件页。
   - 当前五月主轴：13 个主节点
   - PUBLIC INTERACTION：4 条

2. 公开互动采用两种呈现：
   - 05.03 评论互动：附着在 05.04「贺嘉述 杭州→北京 · 法宣阁接站」右页，作为前序公开线索。
   - 05.14《必选题》空降：附着在 05.14 当天主节点右页，作为公开互动旁注。
   - 05.15 空降合集：作为小型互动节点显示，不再占完整事件页。
   - 05.29 YouTube 空降回复：作为小型互动节点；点击后打开「那天，他们回答了什么？」抽屉。

3. 底部时间轴分层：
   - 主节点：原有圆点/菱形
   - 附着互动：主节点圆点右上增加小粉点
   - 独立公开互动：更小的粉色圆点

4. 本章索引：
   - 主轴事件保持正常权重
   - 独立互动以更小、更轻的「公开互动 · 旁注」行显示
   - 已附着到事件页的互动不会重复占一行，只在对应主事件标签显示「+互动旁注」

5. 同步脚本增强：
   如果母数据库存在：
     data\export\public_interactions.json
   网站同步时会优先读取它，并注入 timeline-data，避免以后重导 dual_timeline.json 时互动层被意外丢失。

覆盖后怎么检查
--------------
1. 先备份当前网站文件夹（可选但推荐）。
2. 按目录覆盖上述 5 个文件。
3. 双击：sync_latest_from_database_windows.bat
4. 确认黑框显示「公开互动：4」。
5. 双击：open_preview_windows.bat
6. 打开 PART 03｜五月，重点检查：
   - 05.04 右页出现 05.03 公开互动小纸条
   - 05.14 主节点出现《必选题》公开互动旁注
   - 05.15 不再是一整张普通事件页，而是在索引/底部轴以小互动节点出现
   - 05.29 同理；点击后标题应为「那天，他们回答了什么？」
   - 底部主轴明显比互动节点更醒目

本版不会修改数据库，不会删除图片/视频，也不会覆盖 data/media 内容。
